OpenDesign for GNU/Linux

deb, rpm and Flatpak packages of OpenDesign, the open-source, local-first design agent workspace. Each stable upstream release is repackaged for Linux and published with sha256 checksums.

Install

Pick your package format. The one-liner downloads the latest release, checks it against sha256sums.txt and installs it. You can also download the file and install it yourself.

Debian, Ubuntu .deb

Also Linux Mint, Pop!_OS and other apt-based distros. Installs with apt-get (asks for sudo).

curl -fsSL https://kacperpaczos.github.io/OpenDesign-For-GNU-Linux/install.sh | sh -s deb
Download .deb

Fedora, RHEL .rpm

Any dnf-based distro. Installs with dnf (asks for sudo). On openSUSE, download the file and run sudo zypper install ./open-design_*.rpm.

curl -fsSL https://kacperpaczos.github.io/OpenDesign-For-GNU-Linux/install.sh | sh -s rpm
Download .rpm

Any distro .flatpak

Needs flatpak. Installs the bundle for your user only, no sudo.

curl -fsSL https://kacperpaczos.github.io/OpenDesign-For-GNU-Linux/install.sh | sh -s flatpak
Download .flatpak

No curl? Replace curl -fsSL with wget -qO-. Want to read the script first? View install.sh.

Verify

The one-liner checks the download for you. To check a manually downloaded package, put it next to sha256sums.txt from the same release and run:

sha256sum -c --ignore-missing sha256sums.txt
  • ChecksumsEvery release ships sha256sums.txt.
  • UnsignedPackages carry no GPG signature.
