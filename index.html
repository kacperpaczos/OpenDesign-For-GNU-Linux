OpenDesign for GNU/Linux

We only package. This site publishes automatic builds of the official OpenDesign releases for GNU/Linux — repackaged into deb, rpm and Flatpak on every stable upstream tag. No product code is developed here; everything is destined to go upstream. Packaging sources: github.com/kacperpaczos/OpenDesign-For-GNU-Linux

Unofficial deb / rpm / Flatpak packages of OpenDesign — the open-source, local-first design agent workspace. Built automatically from every stable upstream release, checksum-published, tested on Fedora.
