OpenDesign for GNU/Linux

deb, rpm and Flatpak packages of OpenDesign, the open-source, local-first design agent workspace. Each stable upstream release is repackaged for Linux and published with sha256 checksums.

Install

The one-liner downloads the latest release, checks it against sha256sums.txt and installs it. Or download the package and install it yourself.

Debian, Ubuntu

.deb

Also Linux Mint, Pop!_OS and other apt-based distros. Uses apt-get, asks for sudo.

terminal
curl -fsSL https://kacperpaczos.github.io/OpenDesign-For-GNU-Linux/install.sh | sh -s deb
Download .deb

Fedora, RHEL

.rpm

Any dnf-based distro. Uses dnf, asks for sudo. On openSUSE, download the file and run sudo zypper install ./open-design_*.rpm.

terminal
curl -fsSL https://kacperpaczos.github.io/OpenDesign-For-GNU-Linux/install.sh | sh -s rpm
Download .rpm

Any distro

.flatpak

Needs flatpak. Installs for your user only, no sudo.

terminal
curl -fsSL https://kacperpaczos.github.io/OpenDesign-For-GNU-Linux/install.sh | sh -s flatpak
Download .flatpak

No curl? Replace curl -fsSL with wget -qO-. Want to read the script first? View install.sh.

Verify

The one-liner checks the download for you. For a manual download, put the package next to sha256sums.txt from the same release and run:

terminal
sha256sum -c --ignore-missing sha256sums.txt
  • ChecksumsEvery release ships sha256sums.txt.
  • UnsignedPackages carry no GPG signature.
  • No auto-updateCheck back here or watch the releases for new versions.
